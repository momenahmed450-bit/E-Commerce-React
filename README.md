# 🛍️ ShopMaster | E-Commerce Platform

A modern, high-performance, and responsive E-commerce Web Application built with **React.js**. This project showcases a seamless shopping experience with dynamic data handling and state management.

---

## 🚀 Key Features

* **Dynamic Product Listing:** Displays products fetched from a REST API with detailed views.
* **Smart Shopping Cart:** Full cart functionality (Add, Remove, Update quantity) using Context API.
* **Advanced Filtering:** Users can search and filter products by category or price.
* **User Authentication:** Secure login and registration flows with protected routes.
* **Responsive Design:** Optimized for a perfect experience on Mobile, Tablet, and Desktop.
* **Admin Dashboard:** Specialized views for managing products and user lists.

---

## 🛠️ Tech Stack

* **Frontend:** [React.js](https://reactjs.org/) (Hooks, Router)
* **State Management:** Context API
* **Styling:** CSS Modules / App CSS
* **Icons:** FontAwesome / Phosphor Icons
* **Build Tool:** Vite
